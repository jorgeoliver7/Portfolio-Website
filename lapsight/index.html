      Demo estática de LapSight. La app completa usa Spring Boot, FastAPI (pandas, scipy, scikit-learn), React y PostgreSQL. Aquí el motor analítico está portado a JavaScript para que funcione sin servidor: k-means para stints, Isolation Forest para anomalías, regresión para la degradación y t de Student exacta para los tests.
